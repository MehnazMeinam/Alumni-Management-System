Alumni Management System

Overview

The Alumni Management System is a web-based platform designed to connect alumni, students, and the institution in a single environment. The system helps alumni stay connected with the college community while allowing students to seek mentorship, career guidance, and internship opportunities.

The platform also enables administrators to efficiently manage alumni records, announcements, events, and communication.

Features: 

Alumni registration and login
Student and alumni profile management
Event and announcement management
Alumni directory and search functionality
Career guidance and mentorship support
Internship and job opportunity sharing
Secure authentication system
User-friendly interface

Technologies Used: 

HTML
CSS
JavaScript
Python 
SQLite
Bootstrap
